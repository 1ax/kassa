## Чем шить

По инструкции пользователя «Штрих-М: Сервис обновления ФР» прошивка
заливается **самим Тестом Драйвера** через кабель — либо SD-картой, либо
удалённо из личного кабинета «Облачной кассы». Отдельной утилиты не нужно.

Линия драйвера для 02Ф — KKTLAB/POSCenter 5.18 и новее (на том же FTP:
`a.chernyaev/Драйвер/Драйвер KKTLab 5.18.1089`). Старый Штрих 5.17 — конец
прежней ветки, его удалить полностью. Утилита `fwupdate`/`fwupdater`
из `support/Утилита обновления прошивки/` — Торгового Баланса, и их же
инструкция описывает окно «ККТ не обслуживается нами»; их мигратор меняет
серию прошивки C на T, и обратно только через их поддержку.

## Чем залить не вышло — прогоны 27–28.08.2026

Ни один канал заливки, доступный без вскрытия корпуса, на этой кассе
не заработал. Установлено измерением, а не рассуждением:

| канал | результат | чем установлено |
|---|---|---|
| DFU (USB) | внешнего USB у модели нет | осмотр задней панели: один COM, один Ethernet |
| XMODEM (RS-232) | загрузчик 145 при холодном старте молчит | лог TeraTerm пуст при включении питания; в том же логе `NAK` в ответ на `ENQ` — порт слушается исправно |
| HTTP по TCP | HTTP-сервера в прошивке нет | скан портов: открыт только 7778; драйвер получает `Socket Error # 10061 Connection refused` на `http://<ip>/fwupdate` |
| SD-карта / Flash | карты в слоте нет | `FF4Eh` → «(123) Ошибка оборудования»; т14 «Sdcard status» = 254, 0 секторов |

Версия драйвера ни при чём: одинаково ведут себя KKTLAB 5.18.1092,
POSCenter 5.19.1109 и KKTLAB 5.20.1103. Тайминги тоже: отвал XMODEM наступает
за 1937–2765 мс независимо от «задержки перед записью прошивки».

**Почему XMODEM не идёт.** Вендорская инструкция «Обновления прошивки
процессора системной платы (NXP LPC1778) через протокол XMODEM» от 06.03.2017
требует обратного порядка: сперва запустить в терминале `XMODEM → Send`,
и только потом включить питание ККТ — загрузчик слушает порт первые мгновения
после старта. Загрузчик 145 так не делает: символа `C` при включении не шлёт
(проверено на 115200, 8-N-1, flow control none, нулевые задержки — настройки
из той же инструкции). Тест Драйвера перед заливкой отдаёт недокументированную
команду `WriteFirmware` — строка есть в `DrvFR.dll`, но ни в протоколе v1.18,
ни в открытых источниках такой команды нет; прошивка C.1 62922 её, судя
по всему, не принимает. Отсюда «Не удаётся установить связь по XModem»
при исправной связи с кассой.

**Что говорит протокол.** В спецификации v1.18 команда передачи прошивки
ровно одна — `FF4Eh` «Запись блока данных прошивки ФР на SD карту» (тип файла:
0 — загрузчик, 1 — прошивка; блок 128 байт). Ни XMODEM, ни HTTP в протоколе
не описаны вовсе. Документированный путь заливки для этой кассы один,
и он через карту памяти.

Последняя бесплатная проверка — включение питания с зажатой кнопкой промотки —
сделана 28.08.2026 и тоже ничего не дала: технологический тест отработал
и напечатался, то есть режим запустился, но COM при этом молчал (лог пуст
на 115200). Скорость связи техпрогон не сбросил, вопреки `т17п32` — касса
осталась на 115200. **XMODEM закрыт окончательно:** загрузчик 145 не слушает
порт ни при обычном старте, ни при техпрогоне.

**Остаётся** microSD в слот. Вскрытие корпуса своими руками владелец
отклонил 28.08.2026, так что путь один — **ЦТО**; дальше заливка прямая,
вкладкой «SD-карта / Flash» (`FF4Eh`). Сроки не жмут: ФФД 1.05
предположительно до 01.03.2027, ФН до 14.04.2028.

## Кто это выпустил — не Штрих-М

Проверено 26.08.2026, после прямого вопроса владельца.

АО «Штрих-М» — банкрот: конкурсное производство открыто 15.02.2026,
ООО «Штрих-М» в ликвидации с 01.04.2026. Права на производство части моделей
перешли к ООО «Торговый Баланс М». На живом официальном `ftp.shtrih-m.ru`
в разделе `support/Реестр/` лежат реестровые документы ровно на пять моделей:
ШТРИХ-М-01Ф, ШТРИХ-ON-LINE, ШТРИХ-ЛАЙТ-01Ф, ШТРИХ-ФР-01Ф, ШТРИХ-НАНО-Ф.
**ШТРИХ-М-02Ф среди них нет.**

Единственная прошивка на том FTP — `support/Прошивка/tb_7232_12_esp_22.bin`
от 19.02.2026 (`tb` — Торговый Баланс, `12` — ФФД 1.2, `22` — НДС 22%).
Их же инструкция «Обновление до актуальной версии ПО» предупреждает, что
утилита откажет, если «ККТ не обслуживается нами».

`upd_app_SHTRIH_250425_12.bin` из этой папки — **не оттуда**. Это линейка
KKTLAB (ООО с сайтом kktlab.ru, ПО «ККТЛАБ: Сервис обновления ККТ»,
3600 ₽ по прайсу от 01.07.2025), которая после ухода Штрих-М выпускает
прошивки для «старого парка», включая 02Ф.

**Что это значит.** ККТ должна соответствовать своей записи в реестре ФНС,
где указаны изготовитель и номер версии модели. Прошивка от третьей стороны
этому соответствию может и не отвечать — вопрос не технический, а
регуляторный, и решать его не по этому файлу. Прояснить могут два источника:
запись о ШТРИХ-М-02Ф в реестре ККТ на сайте ФНС (там назван изготовитель)
и ЦТО, который реально обслуживает 02Ф.

## Чему тут верить

**Контрольные суммы выше — не подтверждение подлинности.** Сверять их не с чем:
официального источника нет, издатель хешей не публикует. Они годятся только
на то, чтобы убедиться, что файл не побился при копировании, и что вы шьёте
именно тот файл, который лежал тут 26.08.2026.

Содержимое `.bin` зашифровано — читаемых строк внутри нет, заглянуть и
убедиться, что это прошивка нужной модели, невозможно. Всё, что мы о нём
знаем, — имя и размер из листинга зеркала.

**Если есть ЦТО или партнёр Штрих-М, файлы правильнее взять у них,** а эти
держать как ориентир по имени и дате сборки.

## Что это за файлы

`upd_app_SHTRIH_250425_12.bin` — прошивка серии **C.3**, то есть ФФД 1.2, для
процессора NXP; заявлена для «Штрих-М-01(-02Ф)». В имени дата сборки: 25.04.25.
Нынешняя прошивка кассы — C.1 сборка 62922 от 10.01.2025.

Серия C.3 поддерживает **только** ФФД 1.2: после неё ветка печати 1.05
неприменима.

Сборка **старше введения НДС 22%** (01.01.2026) и старше границы нового
лицензирования (04.12.2025) — последнее и есть причина, по которой взята она,
а не свежее. Для чеков «без НДС» отсутствие ставки 22% безразлично.

По changelog эта сборка чинит печать и ошибку «Команда не поддерживается при
данных настройках» при выключенном запрете произвольной СНО (т17п45=0).

`Poscenter_DrvKKT_5.19_1109_x64.exe` — Тест Драйвера 5.19 линии POSCenter,
сестринской ветки того же «старого парка» (не Торговый Баланс). Взят
27.08.2026 после того, как на 5.18 прошивка по XMODEM встала намертво:
«Не удаётся установить связь по XModem» при исправной связи, физическом
RS-232 и загрузчике 145. Не помогло — 5.19 повторила отказ 5.18 слово
в слово (прогон 28.08.2026, см. «Чем залить не вышло»); подробности —
`ROADMAP.md`, шаги 7 и 7б.

`kktlab_DrvKKT_5.18_1092_x64.exe` — Тест Драйвера 5.18 (Windows). Он же и шьёт
прошивку, отдельной утилиты не нужно. В нём же Мастер Фискализации, которым
делается перерегистрация, и просмотр лицензий — правда, с недавних пор срок
подписки умеет показывать и наша панель обслуживания, читая таблицу 23 поле 15;
командой `1Dh` его не прочитать (ответ `0x37`, прогон 26.08.2026).

## До того, как шить

1. ~~**Проверить поле 11 таблицы 23.**~~ Проверено 26.08.2026: поле 11 «UIN»
   непустое, ключи в кассу зашиты — нужен обычный файл, а не из папки
   «для ККТ без ключей». Панель «Переход на ФФД 1.2» выводит этот признак
   сама, шагом «Ключи зашиты в ККТ».
2. **Подписка.** Прошивка требует подписки, покрывающей квартал, в котором
   сборка выпущена, — а не действующей на сегодня. По инструкции вендора
   («Штрих-М: Сервис обновления ФР») подписка даёт право на все обновления,
   выпущенные до её покупки, и на выпущенные в течение 12 месяцев после.
   Подписка привязана к заводскому номеру; в файле `.slf` коды `FE…` — она,
   `FF…` — бессрочные лицензии. У этой кассы окно закрыто 31.03.2026,
   а сборка датирована 08.01.2025 — покрыта.
3. **Порядок перехода** — на панели «Переход на ФФД 1.2» в программе,
   с фактическими значениями этой кассы.
